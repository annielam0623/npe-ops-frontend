⑧ How to use（默认折叠；紫字是新加的）
📖 How to use — Daily Operation Report
  1. Click + Log an incident to record a complaint, an accident, an emergency or a no show.
  2. For a No show, type the order # and pick the tour date. The product, pickup, driver, guide and vehicle fill in from Main manifest and Dispatch; you can change them.
  3. Once you type an order #, Earlier records lists this order's past reports, ★ Notes and No show marks. Click one to see it.
  4. Add every call, text, WhatsApp or email to the guest in the Contact log. Contacts can't be edited or deleted.
  5. Choose the Guest decision and click Save. Declined or No reply needs a follow-up person and a date: that person gets a task in My tasks on that day. Accepted reschedule needs the new order #.
  6. When the guest boards the rescheduled tour, the report shows ready to close. It never closes by itself: set Status to Resolved.
  7. Farm out orders follow the same steps.
  8. Marking No show in Morning Tracking logs a No show report for you.
  9. Use Updates for anything else you do. Updates cannot be edited or deleted.
📖 How to use — Morning Pickup Tracking（只改 No show 那一条）
  1. If a guest did not show up, click No show in the Bus column. Write a note if you want (optional) and click Save; Cancel changes nothing. Saving also logs a No show report in Daily Operation Report, or adds to the open one for this order and day. Your note is kept in the order's ★ Notes.
  2. To take it back, click the red No show and click Save. If nobody has worked on the No show report yet, it is closed; otherwise it stays open with a line saying the No show was cleared.
  3. Your change shows on Main manifest, the Bus Manifest page and the order page. The guide's own mark is kept: hover over the mark to see it.

T1Morning Tracking 的 No show 弹窗：按 Save 一步存，还是还要再按格子旁的 Save？

现在：点 No show 变红暂存，格子旁出蓝色 Save，按了才存（mark-cell.tsx:136-162、:247-257）。G372 要加弹窗写备注，弹窗本身也有 Save / Cancel。

  • A弹窗里的 Save 就是提交：一按就存标记 + 备注 + 建 / 挂 No show 登记，格子直接显示 Saved。Cancel 什么都不改。撤回（点红色 No show 再按格子旁 Save）照现在两步不变。推荐
    理由：弹窗已经是确认那一步，再按一次格子旁 Save 是重复，也容易忘了按。
  • B弹窗 Save 只把备注暂存在格子上（格子变红），还要再按格子旁的 Save 才真存。和现在的暂存方式一致，但标一个 No show 要按两次 Save。

现在：每条登记底行有 Follow-up 下拉，一选马上存（report-item.tsx:213-242）。后端规定：No show 选 Declined / No reply 时必须同时给跟进人 + 期限，否则存不了。

  • ANo show 的跟进人只放在 Guest decision 块里，和决定、期限、新单号一起按一个蓝色 Save 存（先选后存）。底行不出 Follow-up 下拉，只显示文字「Follow-up: 名字 · due Nov 28」。Complaint / Accident / Emergency 照旧。推荐
    理由：跟进人和期限是一起的，分在两处改容易只改一半，后端也会拒。
  • B两处都有：底行 Follow-up 下拉照旧马上存，Guest decision 块里也能选，两处显示同一个人。
