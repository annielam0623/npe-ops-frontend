③How to use 新加的两条（英文原文，加在 Manifests 的 How to use 里）

How to use — Manifests

  • No show: shows Boarded or No show from the guide’s page, or from the relay driver if the guide hasn’t marked the order. Hover over it to see who marked it and when. If the guide didn’t report, pick Boarded or No show (or — to clear it) and click Save next to it. This changes the same mark the guide uses, so Morning Tracking, Bus Manifest and the guide’s page change too. An order that isn’t on a Bus Manifest yet can’t be marked.
  • Notes: a note for staff, one per row. It isn’t printed and isn’t sent to guests. Type the note, then click Save next to it (or press Enter). Press Esc to undo before saving.

④请 Annie 确认（4 题）

题 1 · 两列放在哪

页面：Manifests › Main manifest 列表。现在没有这两列。

A. 放表的最右边，No show 在前、Notes 最后（图 ① 的样子）。推荐：现有的列一列都不挪，staff 不用重新找；两列都能在 ☰ Columns 里关掉，同其他列。

B. No show 紧跟在 Guest name 后面，Notes 放最后：No show 更显眼，但 Pax、Pickup 等列会往右挪。

题 2 · No show 格怎么改

现在（图 ①）：一个下拉，三个选项 — / ✓ Boarded / ✗ No show；改了旁边出蓝色 Save，按 Save 或 Enter 才存。

A. 下拉（图 ① 的样子）。推荐：一格放得下，和 Cfm # 一样「改了出 Save」；看的时候就是绿字 / 红字。

B. 两个点选小键「Boarded」「No show」并排，点中的变绿 / 变红，再点一次清空，也要按 Save：一眼看到两种选法，但每行多占约 140px 宽。

题 3 · 鼠标移到 No show 上显示什么

A. 只写现在这个结果是谁、什么时候标的，例如「✗ No show · marked by guide Joe (Bus 12) at 7:42 AM」；staff 改过的写「changed by Lizzie (staff) at 9:15 AM」。

B. 在 A 下面再写另一方标的（图 ① 第 2 行的样子），例如再加一行「Relay driver: ✓ Boarded · Mike (Van 3) at 6:58 AM」。推荐：导游和 relay 司机说法不一样时，opening shift 能看出来再决定要不要改。后端要把两方都带上，我们会跟后端核对。

题 4 · Notes 格的样子

现在（图 ①）：同 Cfm # 的单行输入框，宽约 170px，太长的字在框里横向滚动，鼠标移上去显示全文。

A. 单行输入框（图 ① 的样子）。推荐：存法同 Cfm #，一行高度不变，表不会被撑高。

B. 点了弹出一个多行小框写，写完按 Save：能写长一点，但多点一下才能改。

都按推荐的话回「同意推荐」就行；你说「动手」以后才写代码。No show 先做（后端不用迁移）；Notes 要等后端迁移、你执行以后才能上线。
