4. 数据从哪来、到哪去

数据从哪来到哪去
Texts（司机 / 导游短信）原来的 template settings（tmpl__global__field_driver_sms / field_guide_sms），不动Dispatch › Send 发出去，同现在
Quick Replies原来的快捷回复接口，不动司机页 Text 对话框，同现在
Phone Pages 的勾在这里选团、勾，按 Save 存（新的设置，每个团 × 每种手机页一份）后端出司机页、导游页时读它，不显示被勾掉的字。不进打印、Excel、Bus manifest 屏幕
Bus manifest 隐藏列bus_manifest_hidden_columns（每个团一份）只到 Bus manifest 屏幕、打印、Excel；跟上面那份互不影响
客人的字（名字、单号、餐…）Main manifest（订单流不变）同现在，只是显示 / 不显示
